## 2.3.1 — 2026-11-03

### Changed

- The package form is grouped into sections with links beside it, says how many users have the package, offers **Copy** and **Delete** in its head, keeps **Save** in view with a note about unsaved changes, and asks before leaving with changes.
- Node.js, Docker apps and app processes have their switch in the card head; their settings stay greyed out while the switch is off. Memory and CPU limits are entered as a number with a unit or **Unlimited**, and reselling has its own switch with the packages to assign picked from a list.
- The FTP tab of a web domain lists the additional FTP accounts in a table with search, sorting and pages; **FTP account** adds one in a dialog, each row has **Edit** and **Delete**, and selected accounts are deleted together. The buttons in the head of the domain page are smaller.

### Fixed

- An administrator who changes the app process settings of a package on the package form saves them; before, only a reseller's changes were saved.
- REST API v2 names the fields of refused app process settings of a package as the request does (`app_processes.max`), not with the form's names.
- Confirmation dialogs leave room between their question and the buttons.
