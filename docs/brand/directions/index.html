ArcPanel brand directions

Three directions for the ArcPanel brand kit (spec 2026-10-04-001, WP1). Each has a path-built wordmark, a square icon built on an arc, light and dark palettes and an SIL OFL font pairing. Direction A is the current default in docs/brand/; the owner can swap it by re-running the generator with another direction.

Product name: ArcPanel (one word, capital A and P). Based on HestiaCP.

A · Arch Default

Calm indigo, a monoline wordmark whose A is an arch. Quiet, technical, trustworthy.
